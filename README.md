# HeartVerse

버블챗 스타일의 캐릭터 대화형 에피소드 플랫폼 프로토타입.

- 데모: https://claude.ai/artifact/3sfDYFeJ13dHrkWwBFj1YG (비공개, 공유 시 열람 가능)
- `index.html` 하나로 동작. 브라우저에서 직접 열면 MY → 설정에 Anthropic API 키를 넣어 사용 (AI 이미지 생성은 Gemini API 키)

## 주요 기능
- 캐릭터·세계관 탐색, 상세 페이지, 게임 모드(시작 상황) 선택
- 세계관 군상극 신작 3편(「살아남는 자가 역사를 쓴다」): 대연궁 검시록, 백야호: 열세 번째 겨울, 십절곡: 백 일의 봉문 — 각 히로인 5인·시작 상황 3개·키워드북
- 서사 엔진: 인과·연속성·감정의 축적·떡밥 회수를 지키는 서사 원칙, 호감도 단계에 맞는 태도, 원인과 감정 변화를 남기는 장기기억 요약
- 대화방: 지문/대사 서식, 상태창, 다시 쓰기·버전 넘기기, 수정·삭제, 북마크, AI 추천 답변
- 장면 이미지: `[[img:인물코드:상황번호]]` 태그 + 이미지 슬롯(상황 15종)
- AI 이미지 생성(Gemini API 키): 이미지 슬롯·표지·페르소나 이미지를 프롬프트로 생성, 빈 슬롯 한 번에 채우기. 설정의 그림체 프리셋(기본값: 웹소설 표지 세미리얼 2.5D / 동양 판타지 일러스트 / 직접 입력)이 모든 프롬프트 앞에 자동으로 붙고, 그림체 참고 그림(최대 3장)을 함께 보내 그림체를 맞춤
- 세계관 일러스트: 작품마다 대표 일러스트(표지)와 키워드북 항목별 장면 일러스트를 AI로 만들거나 올려서 작품 소개에 표시
- 장기기억: N턴마다 자동 요약, 한도 초과 시 압축·히스토리 보관
- 키워드북: 대화에 키워드가 나올 때만 해당 설정을 AI에 전달, 반영된 키워드는 말풍선 아래 📖로 표시
- 추천 답변 바로 보기: 응답과 함께 온 행동·대사 3개를 입력창 위에 바로 펼침(출력 설정에서 끄기)
- 출력 설정(기억력·출력량·리롤 지침), AI 모델 선택(라이트·스토리·마스터)
- 하트·PLUS 요금제(데모 결제), 하트 사용 내역
- 크리에이터 스튜디오, 커뮤니티 공개, 페르소나
